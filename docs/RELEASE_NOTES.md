## aino player v0.5.5

- 完善漫游电台：只使用平台相似歌曲与相关推荐，按歌名搜索仅定位推荐种子；不再把同名搜索结果当作风格相似歌曲。
- 加强歌手去重，合唱的每位歌手均计入近期限制；候选重复或推荐失败时自动尝试其他已启用平台并延后重试。
- 歌词缺失时自动在已启用的网易云、QQ、酷我、酷狗、咪咕匹配同一录音，失败间隔重试，最多三轮，无需先打开歌词侧栏。
- 修复歌词加载异常后的状态恢复，补译失败保留已显示的原文；手动指定歌词失效时继续自动匹配。
- 修复曲目版本负索引越界，清理无效分页状态和废弃标签实现，整理多项编译告警并补齐开发文档。
- 保持 aino UI 库 v0.5.4 和原生 Wayland 支持；撤回未确认的 IME 定时器实验，保留现有输入法基线。

平台推荐、账号权限与网络状况仍影响在线功能；B 站返回相关推荐。Wayland 桌面集成仍依赖 XWayland。
