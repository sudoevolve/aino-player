## aino player v0.2.3

### 更新内容

- **Windows 中文输入**：撤回未经实机确认的 aino IME 实验，恢复已确认正常的基线。播放器在图标和音频初始化之前建立 UI STA，修正 COM 引用与音频退出顺序；用户已实机确认搜索输入恢复正常。
- **音量与进度条**：松手时保留刚提交的值并补绘下一帧，修复第一次调节后弹回、需要再点一次的问题。
- **流式播放**：通过内置精简 FFmpeg 边解码边播放，PCM 使用固定三秒环形缓冲；不支持管道读取的容器或断流会尝试完整文件回退。网络定位保留暂停状态，但仍需重新解码到目标位置，尚无无缝切歌。
- **任务取消与退出**：切歌、取消下载和关窗会通知网络与解码任务停止；下载最多同时执行两项，点播优先于预加载，避免旧任务继续占用资源。
- **搜索分批显示**：先完成的音源先展示，支持加载更多及失败音源重试，不必等待全部音源一起返回。
- **本地资料库管理**：读取音乐标签与内嵌封面，支持歌单内搜索、排序、多选删除、重命名、队列顺序调整，以及收藏和歌单的导出、备份恢复。收藏保存交给单个后台任务，合并连续修改。
- **Linux 资源与图标**：减少队列、搜索结果和本地歌单的重复复制；按字符覆盖筛选字体回退，使用系统图标主题和目标尺寸封面解码。保留原有歌词画面、字号及动画，不承诺固定内存占用。
- **输入与登录播放修复**：文件夹选择在后台处理，避免阻塞主界面；同步浮层输入隔离修复。网易云标准音质使用已登录账号请求播放地址，并保留实际接口拒绝码；不绕过会员或平台权限。

保留 Windows 压缩安装器、便携版、Linux deb、外部官网登录、B 站分 P、右键菜单、播放模式、定时器和 GitHub 更新检查。升级保留配置、收藏及已下载音乐。

### 安装与升级

- **Windows x64**：推荐 `aino-player-v0.2.3-setup-windows-x64.exe`，按当前用户安装，无需管理员权限；同时提供 `aino-player-v0.2.3-windows-x64.exe` 便携版。可从播放器设置检查更新并运行安装器覆盖升级。
- **Ubuntu 22.04+ / Debian 12+ amd64**：下载 `aino-player_0.2.3_amd64.deb`，使用软件安装器或 `sudo apt install ./aino-player_0.2.3_amd64.deb`。建议安装 `fonts-noto-cjk`。
- 官网登录回传使用受支持的 Chrome / Edge / Chromium，无需扩展和内嵌 WebView；Firefox 暂不支持。

### 验证与边界

发布流程在 Windows/Linux 编译并运行交互、资料库、业务、隔离浏览器回传及内置音频解码回归；Linux 另检查 DPI、字体缓存、deb 安装和 Xvfb 启动。两端检查通过后才发布附件；自动化登录仅使用假 Cookie，Windows 中文输入由用户实际确认。

Linux 仍为 X11/XWayland；原生 Wayland、混合 DPI 多显示器、真实 Linux 音频设备及手机扫码登录仍需实机验证。内存随窗口、音频和封面变化，CI 首帧诊断不能代替相同播放场景对照。YouTube Music 仍属实验功能，本次不运行真实 YouTube 网络测试。

附件含 `SHA256SUMS.txt`、精简 FFmpeg 对应官方源码包、两平台构建信息和许可证。
