## aino player v0.2.5

### 新增功能

- **歌手与专辑**：点击底栏歌手、专辑或歌曲右键菜单进入详情；支持多歌手选择、目录内筛选排序、分页和返回。本地曲目按已导入资料归集；B 站对应 UP 主与视频分 P。
- **应用内更新内容**：设置 → 通用 → 版本更新直接读取并显示 GitHub Release 正文，长说明可滚动阅读，保留发布页入口。
- **桌面集成**：Windows / Linux 支持系统托盘、媒体键与系统媒体控制。关闭窗口默认询问到托盘或退出，可记住选择；系统无托盘时不隐藏窗口。Linux 通过 MPRIS 集成桌面媒体控制。
- **播放管理**：增加输出设备选择、最近播放与清空记录，以及封面、歌词写入下载文件的开关。

### 修复与优化

- **界面与交互**：整理发现、搜索、本地歌单三个页面；本地歌单的文件夹、在线链接、当前队列导入分别展示。修复异步刷新导致的条目错位，移除歌单增加确认。底栏歌手与专辑使用贴合文字的透明链接。
- **不可用歌曲跳过**：会员限制、取流或准备失败后按队列规则继续下一首；连续失败不会无限循环，设备故障保留提示，暂停不会擅自继续播放。
- **流式播放恢复**：修复缓冲背压被误判为断流、同一位置反复从头播放的问题；异常回退保留播放位置和暂停状态。
- **QQ 歌手目录**：调整到网页歌手接口，修正请求参数、歌曲及专辑列表字段。
- **Linux 升级**：下载并校验 deb 后通过系统授权覆盖安装，无需先卸载；补全 AppStream 与维护者信息 `sudoevolve@gmail.com`。
- **Linux 资源开销**：整合已完成的系统图标加载与字体资源优化、封面缓存预算；不改变歌词画面和字号，不承诺固定内存占用。

### 安装与升级

- **Windows x64**：推荐 `aino-player-v0.2.5-setup-windows-x64.exe`，按当前用户安装，无需管理员权限；另提供 `aino-player-v0.2.5-windows-x64.exe` 便携版。
- **Ubuntu 22.04+ / Debian 12+ amd64**：下载 `aino-player_0.2.5_amd64.deb`，使用软件安装器或 `sudo apt install ./aino-player_0.2.5_amd64.deb`。建议安装 `fonts-noto-cjk`；应用内安装需要 `pkexec`。
- 更新保留配置、收藏、歌单和下载文件。旧版本的软件安装器若只显示灰色“已安装”，可用上述 apt 命令直接覆盖升级。
- 升级到此版后，后续更新可在应用内查看 Release 更新说明。

### 验证与边界

发布流程在 Windows / Linux 编译并执行交互、资料库、业务、隔离浏览器回传和内置音频解码回归；Linux 另验证 DPI、字体缓存、上一版 deb 覆盖升级和 Xvfb 启动，两端成功后发布附件。

Linux 使用 X11 / XWayland；原生 Wayland、真实设备切换、不同桌面的托盘及系统媒体面板仍需实机验证。第三方歌手目录、真实账号登录和在线曲目受平台可用性、会员与地区限制；自动化测试不代表这些网络接口均已实机通过。YouTube Music 仍属实验功能，不运行真实 YouTube 网络测试。本版未修改已确认正常的 Windows IME。

附件包含 `SHA256SUMS.txt`、精简 FFmpeg 对应官方原始源码包、两平台构建信息及许可证。
