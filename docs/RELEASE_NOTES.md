## aino player v0.5.2

本次集中修复下载标签、异常数据和后台任务恢复问题，保留现有音源接口与已确认的输入法实现。

- 修复 M4A 内嵌封面/歌词时错误移动音频偏移的问题；MP3 保留原有非目标 ID3 信息，其他音频容器不再误写为 MP3。
- 标签改写使用有界元数据与流式拷贝，检查写入、刷盘、关闭和取消结果，失败保留原文件。
- 加强 JSON、数值配置和歌词时间戳的边界校验，修复畸形输入、数值溢出及部分歌词同步问题。
- 修复封面任务异常后队列停滞及登录清理期间重新启动造成的等待问题。
- 下载文件只自动匹配实际选定的平台变体；旧文件和任务保留，来源未经确认的历史记录可从本地打开，不自动冒充其他平台的副本。
- 网易云默认搜索使用 HTTPS；官方取流 API 与 CDN 请求头分离，避免向音频 CDN 转发账号 Cookie，保留普通 HTTP 音频兼容。
- 保留 LX 和本地可信 Provider 的既有接口、登录访问及每脚本限制，没有新增进程总配额或静默收回脚本权限。
- Windows 任务栏歌词沿用主分支已实现的停靠方式；本次没有修改输入法或更换音频引擎。
- 补充离线安全用例、四平台发布验收清单、编译告警与静态分析入口，固定发行流程的第三方 Action 和容器引用。

自动验收不代表每个第三方音源、账号权限和音乐服务都已实际播放验证；服务端变化、脚本支持范围及账号状态仍会影响可用性。
