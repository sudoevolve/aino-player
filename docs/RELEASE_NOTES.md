## aino player v0.2.1

### 更新内容

- **紧凑菜单与防穿透**：播放模式、睡眠定时均改为紧凑菜单，当前模式带勾选，状态行与不可用选项不可点击。自绘歌曲行、歌词、进度条统一遵守浮层输入阻断；外部点击只关闭菜单，Esc 关闭及时恢复交互。
- **音源选中状态**：多选与单选一致，选中使用主题色实底、白字，深浅色均能清楚区分开启与关闭。
- **下载防覆盖**：识别实际格式后排他保存，同名自动编号；并发下载各用独立临时文件，防止覆盖已有 FLAC/M4A 等歌曲。
- **完整队列恢复**：取消 800 首截断，保留所有备用音源、所选音源、当前歌曲和位置，启动后手动续播。兼容旧版；损坏或超过 64 MiB 的文件保留并提示，不静默覆盖。
- **连续搜索**：繁忙时保留最新请求，不再忽略；旧结果不覆盖新请求，封面补全可提前退出。最多一个搜索工作任务和一个最新待处理请求。
- **下一首预加载**：播放时后台准备下一首，命中后复用下载与解码；尊重下一首播放、随机和循环顺序。只保留一个预加载目标，切歌、队列、音质、账号变化及缓存清理使旧请求失效。首次播放和未命中仍需完整缓存，本版不宣称流式或无缝播放。
- **减少播放开销**：QQ/网易云账号歌单只在变化时复制；普通播放进度降为 10 fps，歌词面板展开保留 60 fps。
- **安装升级与界面整理**：加入压缩 Windows 安装器，更新校验大小与 SHA-256 后覆盖升级，同时保留便携版。加入黑白灰图标、关于页、歌曲右键菜单、底栏模式与定时器，歌词和待播清单共用右侧栏；修正关于页对齐。

保留内置精简 FFmpeg、默认发现页、本地文件夹歌单与收藏、B 站分 P、外部官网登录和 GitHub 更新检查。升级保留配置、收藏和下载音乐。

### 安装与升级

- **Windows x64**：推荐 `aino-player-v0.2.1-setup-windows-x64.exe`，按当前用户安装，无需管理员权限；同时提供 `aino-player-v0.2.1-windows-x64.exe` 便携版。v0.2.0 用户首次迁移请运行安装器，后续新版可从设置更新。
- **Ubuntu 22.04+ / Debian 12+ amd64**：下载 `aino-player_0.2.1_amd64.deb`，使用软件安装器或 `sudo apt install ./aino-player_0.2.1_amd64.deb`。建议安装 `fonts-noto-cjk`。
- 官网登录回传使用受支持的 Chrome / Edge / Chromium，无需扩展和内嵌 WebView；Firefox 暂不支持。

### 验证与边界

发布流程检查 Windows/Linux 编译、菜单输入阻断、业务持久化、并发下载防覆盖、预加载取消、隔离浏览器回传和内置音频解码；Linux 另检查 DPI、字体共享、deb 安装和 Xvfb 启动。自动化登录仅使用假 Cookie。

Linux 仍为 X11/XWayland；原生 Wayland、混合 DPI 多显示器、真实 Linux 音频设备和手机扫码登录仍需实机验证。内存随窗口、音频和封面变化，不承诺固定 RSS。YouTube Music 仍属实验功能，本次不运行真实 YouTube 网络测试。

附件含 `SHA256SUMS.txt`、精简 FFmpeg 对应官方源码包、两平台构建信息和许可证。
