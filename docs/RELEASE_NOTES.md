## aino player v0.5.3

本次完善列表导航、设置入口与在线更新体验。

- 打开待播清单、从歌词切回清单或换歌时定位正在播放的歌曲，新增「定位」按钮；普通重绘保留手动浏览位置，移除当前歌曲后不再错误高亮前一首。
- 列表方向键只在选中项超出视口时滚动；快速查找换词或重新打开时复位光标和滚动位置，详情返回恢复之前的浏览位置。
- 设置新增独立「快捷键」分类，与 F1 共用已有全局快捷键配置；改善窄窗口布局及设置子页进入、返回时的滚动行为。
- 修复发现页热搜与歌曲／歌单搜索视图不一致、下载分类空状态、搜索中误报失败、音源页窄窗按钮和提示重叠等问题。
- 歌词版本搜索支持 Enter，重新搜索清理旧候选，空关键词、无匹配和失败均有明确提示；均衡器预设标签按实际参数显示。
- Windows 更新区分安装版与便携版，便携版明确提示下载后退出并替换文件；Linux 按实际安装包类型选择附件，并提供「直接下载包」应对未配置软件源或同步延迟。
- 更新附件严格匹配当前版本，校验大小和 SHA-256；校验信息不完整时转为浏览器下载。新增取消下载、失败重试及更明确的安装状态说明。

沿用现有音源接口、配置格式和已确认的输入法实现。Windows 便携更新仍需手动替换；Linux 软件源升级需先配置对应源。第三方音源与账号的实际可用性仍受服务端及脚本支持范围影响。
