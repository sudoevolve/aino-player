## aino player v0.3.0

### 音源智能切换

- 新增默认开启的“音源智能切换”：按歌曲所属平台和实际音质，优先使用已验证可用、加载快的源，失败后再尝试后续候选。
- 关闭智能切换时，按已验证的平台覆盖数和平均加载耗时选定一个固定源；播放失败不自动切换脚本、取流渠道或其他平台同曲。
- 启动只静默测速一轮，覆盖网易云、QQ、酷我、酷狗和咪咕；取消周期复测、失败自动重试和点播前的隐式预检。导入、重载或手动重新检测时可再测一轮。
- 修复旧成功记录覆盖新失败、列表排名与实际点播顺序不一致的问题；按平台和音质保留测速数据，界面明确标注估算与未完成状态。
- 支持保存近期测速统计，重启后作为速度参考；脚本内容或网络接口变化时清理不匹配的数据。样本通过不代表所有歌曲和音质均可播放。

### 本地资料库与歌单

- 文件夹扫描复用未变化文件的标签，支持可选的后台增量刷新。
- 本地歌单支持目录迁移后重新关联歌曲，以及 M3U / M3U8 导入导出。
- 第三方平台歌单继续分批读取，保存在线歌单时保留完整快照，避免只保存已显示的部分曲目。

### 性能与稳定性

- 减少播放快照、歌单列表和资料库操作中的重复复制，优化歌词可见行定位及音源列表状态缓存。
- 限制后台任务排队数量，为点播保留执行通道；交互请求可优先于低优先级目录请求。
- 完善下载、搜索、文件选择和目录加载的异常恢复，修复失败后持续显示忙碌、无法重试等状态问题。
- 新增通知历史，支持查看完整错误、复制和清空；改进单实例文件打开与启动搜索转交。
- 收紧取流和首段缓冲的共同超时预算，用户切歌取消不计入音源失败。
