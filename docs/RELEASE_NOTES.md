## aino player v0.5.1

本次修复长歌单顺序播放、无缝衔接和预加载的状态同步问题。

- 顺序续播以实际队列位置为准，避免后段重复歌曲被认成前面的条目，导致尚未播完就提前回头。
- 移动歌曲、撤销队列编辑和恢复输出设备时保留当前条目的位置；删除当前歌曲后继续播放原来的后一首。
- 无缝衔接绑定实际切入曲目的标识和入队位置，避免切歌结果被覆盖，或把下一首的错误归到上一首。
- 修复预加载音频仍被缓存持有时就遭取消的问题，阻止复用已取消的流。
- Linux 系统媒体控制关闭随机播放时保留原有非随机模式，避免顺序播放意外变成列表循环。
- 播放诊断增加队列位置、当时模式和最近切歌原因，便于追踪异常跳转。
- 内置 UI 库更新至 aino 0.5.2，保留播放器扩展与已确认的 Windows 输入法实现。
