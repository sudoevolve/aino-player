## aino player v0.5.0

本次集中完善播放可靠性、资料库管理和桌面交互。

- 切换输出设备按当前歌曲身份恢复位置和暂停状态，清空或移除队列后也能正确恢复。
- 撤销改为保存成功后完成；失败可重试，恢复队列的下一首优先级与随机历史，并支持撤销恢复的歌词偏好。通知里的撤销只对应当前操作。
- 列表支持方向键、Home / End、Shift 连选、Enter 播放和 Delete 移除，Esc 按焦点分层处理；Windows / X11 全局快捷键可配置，冲突会提示。
- Ctrl+K 快速查找在后台建立索引，按匹配程度排序，为歌曲、歌单、歌手分别保留结果名额。
- 下载补充添加／结束时间、大小、取消和文件缺失状态，可排序并重新定位移动的文件；进度刷新不再反复写入记录。
- 单曲和多选都可添加到指定歌单，或现场新建歌单，自动去重并反馈数量。
- 备份使用原生文件选择器，提供自动备份列表、逐个歌单选择、缺失文件检查和恢复结果。
- 封面失败后有限退避重试，也可手动重试；未实现歌手／专辑目录的平台保留文字、关闭无效跳转。
- 歌曲右键“本次选源”显示实际尝试顺序、采用原因和跳过原因，不额外测速，也不展示播放链接或登录凭据。

保持现有歌词布局，没有新增运行依赖，也没有修改上游 aino 或输入法实现。
