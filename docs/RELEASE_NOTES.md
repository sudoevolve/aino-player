## aino player v0.3.3

### 悬浮歌词

- 新增 Windows 与 Linux Xorg 悬浮歌词，支持拖动到 Windows 任务栏或 Xorg 顶栏区域，以及拖出恢复悬浮。
- 支持单双行、译文或下一句、字号、宽度、透明度、置顶、锁定与鼠标穿透，并保存位置和外观设置。
- 已唱、未唱和背景颜色可分别调整；歌词按行内时间估算填充进度，复用字形缓存，避免每次刷新重新绘制文字遮罩。
- Wayland 下提供普通悬浮歌词，顶栏停靠受桌面环境限制。

### 音源与播放

- 每个音源分别显示网易云、QQ、酷我、酷狗、咪咕五个平台的状态，避免某个平台失败导致整个源被标红。
- 新增单个音源静默检测；关闭智能切换后可拖动排序，按手动顺序固定使用音源。
- 修复单曲播放失败污染整个平台健康状态的问题；短暂网络错误与单曲不可播分别处理，不自动删除源文件。
- 播放、预加载和下载保持歌曲所属平台；失败后不再跳到其他平台的同名歌曲。
- 调整音源操作区排版，分开平台状态与“检测、详情、移除”按钮。

### 性能与项目主页

- 减少音源初始化时整份脚本和 HTTP JSON 的中间副本，在初始化与静默检测批次结束后回收临时对象及空闲堆页。
- 修复音源 HTTP 响应为普通文本时被宽松 JSON 解析截断的问题，保留中文、空白与原始响应字节。
- Windows 同一批音源短测中，私有驻留内存由 v0.3.0 的约 36.8 MiB 降至约 34.3 MiB；实际占用随脚本和网络返回变化。
- 新增简洁项目主页，默认跟随系统深浅色主题，集中展示截图、下载、常见问题与爱发电捐赠入口。
- 合并 FarnaHerry 的软件源贡献，新增 Fedora 44+ RPM 与 Arch Linux 包，以及签名的 DNF / pacman 软件源和一键安装入口。
