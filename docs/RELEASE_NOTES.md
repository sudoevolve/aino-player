## aino player v0.2.8

### 歌词与播放

- 补齐多平台中文译文：QQ 分别解码原文与译文；酷我、酷狗增加原文读取；咪咕读取 MRC 时间轴和中文译文。
- 外语歌缺少译文时，校验歌名、歌手、时长及原文后尝试同曲补译文，保留当前平台时间轴。原文先显示，失败可重试，切歌取消旧请求。
- 歌词底部可开关译文，下载的 LRC 包含译文。保留歌词居中、渐隐和滚动效果，改为仅在滚动时连续刷新，减少静止时重绘。

### 歌单与交互

- 网易云歌单按完整曲目 ID 分批补全，修复只显示 10～20 首；补全失败明确提示，避免残缺数据覆盖本地歌单。
- 网易云、QQ、酷我、酷狗、咪咕支持搜索在线歌单；发现页热门歌单与歌单搜索均支持加载更多。
- 歌曲单击选择、Ctrl 增减、Shift 连选、Ctrl+A 全选、Esc 清空；双击或点击封面播放。搜索、歌单、歌手 / 专辑、最近播放和待播清单均支持批量操作。
- 批量收藏、加入队列、下载、移除；右键保留已选组，工具栏固定高度。优化窄窗口排版、选中状态、歌词来源及设置页间距。

### 启动、资源与安装

- 启动自动恢复已导入的第三方音源；统一保存到用户配置目录，Windows 自动复制当前 EXE 旁缺失的旧脚本，保留原文件与移除记录。
- 离屏封面超时回收，关闭歌词释放排版缓存，后台回收空闲脚本内存；Windows Release 优化代码体积。
- **Windows x64**：推荐 `aino-player-v0.2.8-setup-windows-x64.exe`；另提供便携 EXE。
- **Ubuntu 22.04+ / Debian 12+ amd64**：`aino-player_0.2.8_amd64.deb`，可用 `sudo apt install ./aino-player_0.2.8_amd64.deb` 覆盖升级。
- 已添加项目 APT 源：`sudo apt update && sudo apt install aino-player`；首次安装见 [README](https://github.com/sudoevolve/aino-player#readme)。保留配置、收藏与歌单。

### 使用范围与验证

译文取决于平台已有内容及可靠的同曲匹配，不包含机器翻译；没有译文时仍显示原文。酷我、酷狗、咪咕歌单打开目前最多 200 首。Linux 使用 X11 / XWayland。本版没有输入法修改。

附件仅在 Windows、Linux 发布检查通过后上传，包含安装器、便携 EXE、deb、SHA-256 校验及 FFmpeg 对应源码和许可。自动检查覆盖业务、交互、浏览器登录回传和内置音频解码；在线诊断已验证咪咕原文与译文时间对齐。真实账号、全部在线歌曲及不同桌面的实际表现仍需实机确认，未宣称 CPU 或内存的固定降幅。

发布验证已完成：Windows 6 项、Linux 8 项回归全部通过，Linux 已验证 0.2.7 → 0.2.8 deb 覆盖升级、AppStream 和安装后启动。[发布检查记录](https://github.com/sudoevolve/aino-player/actions/runs/43484721783)。所有产物来自标签提交 `d7c3045`。签名 APT 源已同步到 0.2.8，公开索引的 deb 摘要与 Release 一致。

Windows 便携 EXE 为 7,840,256 字节，比 v0.2.7 的 8,657,920 字节减少约 9.4%；安装器 4,566,845 字节，deb 3,156,100 字节。
