## aino player v0.4.1

### 播放体验

- 新增十段均衡器、前级增益及低音、人声、柔和预设，默认关闭，设置自动保存；无需额外音效库。
- 新增可选实时响度均衡，平滑歌曲音量差异并限制峰值，不修改原始文件。
- 下一曲预加载完成后，在同一音频输出中无缝衔接；未准备好时沿用正常切歌。
- 流式中断先刷新地址并从断点恢复，连续失败后尝试完整文件，重试次数有上限，避免反复从头播放。
- 缓冲阈值随欠载调整，界面区分解析、地址验证、缓冲、下载、解码和恢复阶段；新增可复制的播放诊断。

### 性能与桌面体验

- 空闲第三方音源按需释放 JS 执行环境，保留状态和测速记录，下次使用自动唤醒；降低脚本初始化并发，减少同时持有的临时资源。
- 播放队列与保存任务共享只读快照，修改时才复制，减少大队列刷新和保存的额外分配。
- 歌词侧栏新增桌面歌词快捷开关；减少悬浮歌词重复定位和 X11 窗口置顶操作，改进多显示器边界与 Windows 独立 DPI 处理。
- Linux 更新识别 APT、DNF、pacman 安装归属，提供对应更新命令；便携版选择当前系统对应的软件包。
- 修复测速更新导致下一曲预加载反复失效，以及输出设备、托盘和关闭行为部分设置未恢复的问题。
