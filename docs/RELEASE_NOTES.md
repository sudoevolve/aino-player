## aino player v0.2.9

### 本地播放

- 支持拖入本地歌曲和文件夹、Ctrl+O 多选打开，以及系统文件管理器双击音乐文件；后台读取标签与封面，路径去重后加入队列。
- 设置中可注册默认音乐播放器。Windows 打开系统默认应用设置完成选择；Linux 注册桌面文件与音频 MIME 关联。
- 文件打开优先转交已有窗口；拖入文件不会自动新建永久歌单，可将当前队列保存为本地歌单。
- 本地歌曲右键支持打开所在文件夹；批量下载自动跳过已经在本机的歌曲。

### 更快地选择音源

- 静默检测记录取址和音频样本加载耗时，实际播放记录流式首段就绪耗时；优先使用已验证可用、加载快的源。
- 按平台、实际音质分别统计，使用平滑耗时减少波动；短期连续失败降级，仍保留兜底，切歌取消不计失败。
- 音源列表显示样本毫秒数，详情可查看取址、样本加载及首段就绪时间；状态按版本缓存，减少反复复制。
- 后台检测最多两个并行任务，每次读取最多 64 KiB，不播放声音，也不下载整首。测速只保留本次运行；QQ、网易云使用固定样本，其他平台由实际点播积累。

### 安装与更新

- **Windows x64**：推荐 `aino-player-v0.2.9-setup-windows-x64.exe`，另附便携 EXE。
- **Ubuntu 22.04+ / Debian 12+ amd64**：`aino-player_0.2.9_amd64.deb`，使用 `sudo apt install ./aino-player_0.2.9_amd64.deb` 覆盖升级。
- 已添加项目 APT 源：`sudo apt update && sudo apt install aino-player`；首次安装见 [README](https://github.com/sudoevolve/aino-player#readme)。

Windows、Linux 发布检查通过后自动上传安装器、便携 EXE、deb、校验清单及 FFmpeg 对应源码和许可。Linux 使用 X11 / XWayland；本版没有输入法修改。系统关联、文件管理器拖放和各桌面环境仍需实机确认；测速代表加载延迟，不是持续带宽，也不保证所有账号和歌曲均可播放。
