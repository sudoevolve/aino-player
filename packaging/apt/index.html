Aino Player

项目官方 APT 源 · Ubuntu 22.04+ / Debian 12+ · amd64 · 当前版本 @VERSION@

首次添加软件源：

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://sudoevolve.github.io/aino-player/apt/aino-player-archive-keyring.gpg | sudo tee /etc/apt/keyrings/aino-player-archive-keyring.gpg > /dev/null
curl -fsSL https://sudoevolve.github.io/aino-player/apt/aino-player.sources | sudo tee /etc/apt/sources.list.d/aino-player.sources > /dev/null
sudo apt update
sudo apt install aino-player

后续使用系统更新或 sudo apt update && sudo apt upgrade。无需先卸载，配置、收藏和歌单会保留。

缺少下载工具时先运行 sudo apt install curl ca-certificates。

公钥指纹：
@FINGERPRINT@
可用 gpg --show-keys --with-fingerprint /etc/apt/keyrings/aino-player-archive-keyring.gpg 核对。 此密钥通过 Signed-By 仅用于本软件源。

这是开发者提供的软件源，尚未收录于 Ubuntu 官方仓库。
