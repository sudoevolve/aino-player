Aino Player

项目官方 pacman 源 · Arch Linux 及衍生发行版 · x86_64 · 当前版本 @VERSION@

手动添加（先导入并本地签名公钥）：

curl -fsSL https://sudoevolve.github.io/aino-player/arch/aino-player.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key @FINGERPRINT@
sudo tee -a /etc/pacman.conf > /dev/null <<'EOF'
[aino-player]
Server = https://sudoevolve.github.io/aino-player/arch/x86_64/
SigLevel = Required DatabaseOptional
EOF
sudo pacman -Syu aino-player

导入后可用 sudo pacman-key --finger @FINGERPRINT@ 核对指纹。仓库数据库和软件包均由此密钥签名，缺失或损坏的签名会让安装失败。

后续随 sudo pacman -Syu 一并更新，无需先卸载，配置、收藏和歌单会保留。

卸载应用：sudo pacman -Rs aino-player。停止使用此软件源：删除 /etc/pacman.conf 中的 [aino-player] 段落，并运行 sudo pacman-key --delete @FINGERPRINT@。

这是开发者提供的软件源，不是 AUR 包，也不收录于 Arch 官方仓库。
