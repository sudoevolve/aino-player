Aino Player

一个播放器，听在线音乐，也听自己的收藏。

  • 简洁的界面，支持浅色与深色主题
  • 多平台搜索、发现音乐和在线歌单
  • 智能选择可用且加载快的音源，也可固定使用一个源
  • 同步歌词、中文译文与播放队列
  • 本地音乐、收藏、文件夹歌单和资料库备份
  • 内置精简 FFmpeg，支持 AAC / M4A 播放

常见问题

需要登录或安装浏览器扩展吗？

无需浏览器扩展。网易云、QQ 的账号登录使用外部官网登录并自动回传，支持 Chrome / Edge / Chromium。第三方音源与自带接口分别管理；平台会员和地区限制仍然生效。

如何添加音源？为什么没有一直测速？

在“音源”页导入兼容的 LX 脚本，或使用在线获取；重启会自动恢复。启动只静默测速一轮，之后可手动重新检测。智能切换默认开启，关闭后固定使用一个源。脚本接口、歌曲版权与音质都会影响可播性。支持范围

如何播放本地音乐？

拖入歌曲或文件夹，也可按 Ctrl+O 多选打开；当前播放队列可以保存为本地歌单。在设置中可配置默认音乐播放器。收藏、歌单与本地文件都由你自己管理。

Linux 有什么要求？

提供 amd64 的 DEB 包，支持 Ubuntu 22.04+ / Debian 12+。界面使用 X11 / XWayland，建议安装 fonts-noto-cjk；托盘显示取决于桌面环境支持。APT 软件源说明
