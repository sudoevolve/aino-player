# 平台目录与第三方音源

平台负责找歌，第三方音源负责将平台歌曲 ID 换成播放地址，两个入口分别管理。

| 平台 | 搜索 / 发现 | 播放 | 歌手 / 专辑 |
| --- | --- | --- | --- |
| 网易云、QQ | `netease.js` / `qq.js`，热搜、热门歌单 | 自带账号接口或 LX 的 `wy` / `tx` | 已接入 C++ 目录 |
| 酷我、咪咕 | 对应平台 JS，热搜、推荐歌单、官方榜单 | 需要声明支持 `kw` / `mg` 的 LX 音源 | 暂未接入 |
| 酷狗 | `kugou.js`，热搜、推荐歌单、官方榜单 | 需要声明支持 `kg` 的 LX 音源 | 暂未接入 |
| B 站 | C++ 搜索 | 自带音轨、分 P 接口 | UP 主、视频分 P |

搜索只有 JS 一份实现。搜索页、歌词匹配和自动换源复用它，接口报错时直接显示原因，不再暗中重复请求另一份 C++ 搜索。推荐歌单与榜单可分页打开、播放，也可保存完整曲目快照到本地歌单并刷新。链接导入支持网易云、QQ，以及酷我 `www.kuwo.cn/playlist_detail/ID`、酷狗 `www.kugou.com/yy/special/single/ID.html`、咪咕 `music.migu.cn/v3/music/playlist/ID` 的官方完整地址；短链接须先在浏览器展开。保存前会继续读取全部页面，读取失败、返回重复页面或超过 10000 首上限时保留原快照并提示原因，不把当前已加载的第一页冒充完整歌单。

QQ 热搜使用官方 `GetHotkeyForQQMusicPC`，主入口失败后限时尝试备用官方入口。热搜先于歌单发布到界面，切换平台会取消旧请求；刷新失败保留旧热词并显示状态。简短错误与完整详情分开显示，详情可滚动、复制，不把 JS 调用栈直接画进热搜区域。酷狗歌单从移动端推荐目录读取，曲目走官方 HTTPS 网关的歌单接口，`playlist:` 与 `rank:` ID 独立保存，支持本地保存及远端刷新。

默认平台 JS 在构建时内嵌到播放器；无需随 EXE 手动复制文件。Windows 可用 EXE 同级 `providers/` 覆盖，Linux 先查可执行文件同级目录，再查 `/usr/share/aino-player/providers`；`AINO_PROVIDER_DIR` 可指定覆盖目录。编辑后重启生效，覆盖脚本出错不会默默改用旧接口。

## 平台脚本契约

```js
globalThis.provider = {
  key: 'netease',
  name: '网易云',
  search(keyword, page, limit) { return [/* song */] }, // page 从 0 开始
  heats() { return [{text: '热搜', heat: 0}] },
  playlists({page, limit}) { return {items: [{id: '歌单或 rank:榜单ID', name: '标题', cover: '', official: false}], more: false} },
  playlist_search({query, page, limit}) { return {items: [], more: false} },
  lyric({id, native_id, title, duration_ms}) { return {lyric: "LRC", translation: "译文 LRC"} }, // 可选
  board(id, page, limit) { return {items: [/* song */], more: false, total: 0} } // rank:榜单ID / playlist:歌单ID，page 从 0 开始
}
```

`song` 包含 `id`、`title`、`artist`、`album`、`duration_ms`、`bitrate`、`native_id`、`cover`，还可提供 `needs_login`、`artists: [{id,name}]`、`album_id`。酷狗另存 `album_audio_id` 和 `quality_hashes`，咪咕用 `native_id` 保存 `copyrightId`，这些字段随收藏、队列和歌单持久化。

宿主提供 `ctx.http(url, {method,headers,body,timeout})`、`ctx.cookie('netease'|'qq')`、`ctx.md5`、`ctx.b64encode`、`ctx.b64decode`、`ctx.log`。HTTP 返回 `{statusCode,body,bodyText,headers,error}`；目录方法使用同步 HTTP。可选 `resolve(song, quality)` 仅供平台自带直链，不得反向调用第三方源冒充自带渠道。

集合锁只用于取得 `shared_ptr` 或交换列表；各平台独立运行时锁覆盖参数创建、JS 执行和释放。等待可取消，网络期间不持集合锁；调用线程持有自己的凭据快照。搜索和取流等待时可取消低优先级的榜单、推荐、热搜及歌词请求，让交互先取得运行时；被取消的目录读取保留已有结果并显示可重试错误，不复制额外的 JS 运行时。重载不释放仍被请求持有的旧运行时。歌曲转换只保留模型需要的字段，文本字段限制为 8 KiB、参与歌手最多 32 项，避免每首曲目完整 JSON 的重复编解码和保留。

## 第三方音源

导入、获取或重载后，后台分别对每个脚本的 QQ、网易云样本请求播放地址，最多两项并行，再用 Range 有界读取最多 64 KiB 音频样本，记录取址及样本加载耗时。不会播放声音或下载整首；检测优先让位于点播。实际取流与界面复用当前平台、实际音质的同一套排序：已验证可用、未知、失败，组内按加载延迟及文件名稳定排序。较新的样本失败优先于旧成功记录；实际取流一次失败就降级 60 秒，保留最终兜底机会，只有返回 URL 不会清除失败，重新验证音频成功才会清除失败记录。每次换源重新读取排名，取址阶段失败候选单次最多 3 秒，其他候选最多 8 秒；同一候选连同音频验证共用 5 / 15 秒启动预算，单个平台第三方候选共用 30 秒预算，整次点播共用 60 秒预算。预算通过取消信号传递，实际返回还受底层取消响应粒度影响，不是强制终止线程。已开始的流式播放保留独立生命周期，启动预算到期不会截断它；整首下载回退也消耗启动预算，慢网络可能转试其他候选。用户取消不计失败，候选超时计失败。

速度优先比较同音质的 64 KiB 样本总延迟；未测音质使用同平台样本作估算，缺少样本才使用真实首段就绪耗时作估算，界面明确标注。实际首段耗时也独立保留在详情中，不把不同测量口径的数字都标成实测样本速度。退出时将有效统计保存到配置目录的 `source-timings.json`，最多 1 MiB；恢复要求脚本内容指纹、活动网络接口地址摘要一致且未超过六小时。恢复数据只作延迟估算，不能冒充本次已验证成功；网络接口签名变化清除统计与检测健康状态。签名不包含凭据，仅本地存储摘要；同地址下代理、DNS 或路由变化不一定能识别，可手动重新检测。重载或移除脚本后清除对应统计。样本不代表所有歌曲、所有音质可播，也不代表持续下载带宽。酷我、酷狗、咪咕目前通过实际点播积累耗时。近期取流错误分平台保留在详情中；列表圆点表示当前排序平台的状态，其他平台的检测结果仍可查看。

“移除”只记录应用内禁用，不删除 JS。重新加载尊重移除记录；主动“在线获取”会恢复并加载本次成功下载的脚本，汇总下载与初始化失败数量；查看未加载列表也可逐个恢复或重新导入。Windows、Linux 均将音源保存在用户配置目录的 `sources/`，支持 `AINO_LX_DIR` 覆盖；正常启动自动后台加载。Windows 自动将当前 EXE 同级旧 `sources/` 中缺失的脚本复制到新目录，不覆盖已有版本，也不删除原文件或解除移除记录。运行错误保留具体原因，不把“初始化成功”称为“可播放”。

LX 宿主契约对照 lx-music-desktop `323e4bac505da428adae8db6b58039fb2b36b86d`：API 版本为 `2.0.0`，`send/on` 返回 Promise，初始化会完成监听器注册。取流保留初始化任务，只清理本次请求的定时器和网络任务；HTTP 独立并行、可取消，每个脚本最多 16 项，JS 回调仍只在运行时线程执行。响应包含 raw 字节和响应头，MD5 / Base64 按字节处理 Buffer，currentScriptInfo 包含 rawScript。

尚未实现 AES / RSA、zlib、multipart formData、脚本的 `lyric` / `pic` 消费及完整 Node API，不能宣称所有脚本兼容；DNS 失败、服务端下线和账号权限也会影响可用性。酷狗榜单通过官方 HTTPS 网关转发，避免旧域名证书不匹配。酷我缺失封面在封面后台队列按需解析，不阻塞榜单读取。各平台播放仍需实际网络与账号确认。

`page` 从 0 开始，`more` 表示平台是否还有下一页；目录宿主继续兼容旧版数组返回值。推荐列表的榜单仅在第一页附加，不截掉该页实际歌单。歌单搜索接入网易云、QQ、酷我、酷狗与咪咕，搜索与发现分别保存查询、页码、错误和结果；加载失败不推进页码，返回重复页面时停止追加。

歌词由播放器优先读取当前平台：网易云 tlyric、QQ trans，以及酷我 / 酷狗原文、咪咕 MRC + trc。MRC 按协议独立实现 64 位 XXTEA 和 UTF-16LE 解码，仅保留行级时间轴，不依赖 Node、机器翻译服务或额外音频库。酷狗目前读取 LRC，未读取 KRC 内嵌翻译。外语原文缺译文时，先校验歌曲标题、歌手和时长，再要求多行原文与时间相符后补网易云译文；原文先发布，补译失败不会隐藏已有歌词。每次请求使用有总时间预算的后台任务，切歌与退出可取消。
